# Jae.dev

My personal developer portfolio — showcasing who I am, my skills, and the projects I've built as I develop my full-stack engineering skills.

🔗 **Live site:** [https://etinosa15.github.io/Jae.dev/]

## About

I'm a software engineer bridging frontend craftsmanship with C# backend architecture. This site is where I share my journey, skills, and projects as I build toward production-level full-stack development.

## Tech Stack

- HTML5 / CSS3
- JavaScript (ES6+)
- C# / .NET
- ASP.NET Core
- SQL
- Git & GitHub

Built with **vanilla HTML, CSS & JS** — no frameworks, no build tools.

## Features

- Responsive, single-page layout with tab-based navigation (Home / About / Contact)
- Dark theme with a minimal, editorial-style design system
- Working contact form (powered by [Web3Forms](https://web3forms.com))
- Direct contact links: email, GitHub, WhatsApp, Twitter/X

## Running Locally

1. Clone the repo: `git clone https://github.com/etinosa15/Jae.dev.git`
2. Open `index.html` in your browser, or use a local dev server like VS Code's Live Server extension.
